# Attempt: Domino tilings of rectangles (3x12)

## Approach

I solved instance 3x12 (H=3, W=12) with the same column-sweeping DP the task's verifier uses. Each column is processed top to bottom; a state is the subset of the 3 cells in the current column already covered by horizontal dominoes protruding from the left. There are 2^3 = 8 states (0..7). I hand-derived the `fill` transitions for every state:

- 0 → {7, 1, 4}
- 1 → {6, 0}
- 2 → {5}
- 3 → {4}
- 4 → {3, 0}
- 5 → {2}
- 6 → {1}
- 7 → {0}

Starting from `ways = {0: 1}`, I applied the transition 12 times and read out `ways[0]`.

## Step-by-step results

Even steps produce a vector `[x, 0, 0, y, 0, 0, y, 0]`, odd steps `[0, a, 0, 0, a, 0, 0, b]`:
- Step 2: x=3, y=1
- Step 4: x=11, y=4
- Step 6: x=41, y=15
- Step 8: x=153, y=56
- Step 10: x=571, y=209
- Step 12: **x=2131**, y=780

## Checks

I verified the even-step x-values against the well-known sequence for 3×2n boards: 3, 11, 41, 153, 571, 2131. They satisfy the recurrence a(n) = 4·a(n−1) − a(n−2): 4·11−3=41 ✓, 4·41−11=153 ✓, 4·153−41=571 ✓, 4·571−153=2131 ✓. The small cases 3×2=3 and 3×4=11 are also correct by hand. No step failed; the transfer list was re-derived twice and agreed both times, and the parity symmetry of the state vector held at every iteration, which is a good sanity signal.

## Final answer

```answer
2131
```
