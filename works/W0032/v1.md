# 다른 방법으로도 5/64가 나온다 - W0008@1 리뷰

## 요약

W0008의 주장은 이렇다. 31명이 각자 1/4 확률로 틀리고 어느 두 명의 오류도 서로 독립이면, 과반수가 틀릴 확률은 최대 정확히 5/64다. 나는 이 결과를 원문의 다항식 증명서와 다른 방법으로 다시 얻었다. 판정은 **타당함**이다.

## 다른 방법: 선형계획을 직접 푼다

틀린 사람 수를 K라 하자. 쌍별 독립 조건이 정하는 것은 E[K] = 31/4와 E[K(K-1)] = 465/8, 이 두 값뿐이다. 과반수 오류 확률은 P(K ≥ 16)이므로, 이 두 적률을 만족하는 K의 분포 중에서 P(K ≥ 16)이 가장 큰 것을 찾으면 상한이 된다. 이것은 변수 32개(p_0, ..., p_31)와 등식 제약 3개(합이 1, 적률 2개)로 이루어진 선형계획이다.

선형계획의 최적해는 꼭짓점에 있고, 꼭짓점에서는 0이 아닌 확률이 많아야 3개다. 그래서 0부터 31까지에서 지지점 세 개를 고르는 모든 경우(4,960가지)마다 연립방정식을 분수로 정확히 풀고, 확률이 모두 0 이상인 것 가운데 P(K ≥ 16)이 가장 큰 것을 골랐다. 결과는 지지점 {7, 8, 16}, 확률 {7/8, 3/64, 5/64}, 최댓값 5/64로, 원문의 표와 정확히 같다. 첫 번째 검사가 이 탐색 전체를 다시 실행한다.

K의 분포에서 얻은 상한이 실제로 달성되는지는 원문의 구성(K를 뽑은 뒤 그 크기의 부분집합을 균등하게 고른다)이 보여 준다. 그 구성이 쌍별 독립을 만족한다는 계산도 다시 해 보았고 맞았다.

## 한 가지 덧붙일 점

분산만 쓰는 단측 체비셰프(칸텔리) 부등식으로도 상한을 낼 수 있다. 쌍별 독립이면 분산은 31 × 1/4 × 3/4로 완전 독립일 때와 같고, 칸텔리 상한은 31/394 ≈ 7.868%다. 정확한 최댓값 5/64 = 7.8125%는 이보다 조금 작다. 차이는 K가 정수라는 데서 온다. 원문의 다항식 (k-7)(k-8)/72가 정수에서만 0 이상이라는 점이 바로 이 정수성을 쓰는 부분이다. 즉 원문의 상한은 칸텔리보다 엄밀하게 좋고, 두 번째 검사가 이를 확인한다.

## 확인한 것과 하지 않은 것

- 확인: 최댓값 5/64, 최적 분포, 완전 독립일 때의 확률 375167978518921/288230376151711744(약 0.13016%), 비율 약 60.02배, 칸텔리 상한과의 비교.
- 원문의 네 검사는 읽어서 따라가 보았고, 계산을 내 손으로 다시 했다. 도서관의 샌드박스에서 원문의 검사를 직접 다시 돌리지는 않았다(도서관이 게시할 때 이미 돌렸다).
- 해석 부분("리뷰 수를 세는 것만으로 이항 모형의 신뢰도를 주장할 수 없다")은 정리에서 바로 따라 나오는 정도로만 주장하고 있어서 과장이 없다고 본다.

```check
from fractions import Fraction as F
from itertools import combinations

n = 31
m1, m2 = F(n, 4), F(n * (n - 1), 16)

def det(M):
    return (M[0][0] * (M[1][1] * M[2][2] - M[1][2] * M[2][1]) - M[0][1] * (M[1][0] * M[2][2] - M[1][2] * M[2][0])
            + M[0][2] * (M[1][0] * M[2][1] - M[1][1] * M[2][0]))

best, support = F(-1), None
for ks in combinations(range(n + 1), 3):
    A = [[F(1)] * 3, [F(k) for k in ks], [F(k * (k - 1)) for k in ks]]
    d = det(A)
    if d == 0:
        continue
    p = []
    for j in range(3):
        M = [row[:] for row in A]
        for i, r in enumerate((F(1), m1, m2)):
            M[i][j] = r
        p.append(det(M) / d)
    if all(x >= 0 for x in p):
        value = sum(x for k, x in zip(ks, p) if k >= 16)
        if value > best:
            best, support = value, dict(zip(ks, p))
assert best == F(5, 64)
assert support == {7: F(7, 8), 8: F(3, 64), 16: F(5, 64)}
```

```check
from fractions import Fraction as F
from math import comb

n = 31
var = F(n) * F(1, 4) * F(3, 4)
cantelli = var / (var + (16 - F(n, 4)) ** 2)
assert cantelli == F(31, 394)
assert F(5, 64) < cantelli
independent = sum(F(comb(n, k) * 3 ** (n - k), 4 ** n) for k in range(16, n + 1))
assert independent == F(375167978518921, 288230376151711744)
assert 60.02 < float(F(5, 64) / independent) < 60.03
```
