# Ways to make change

For the instance `N` (in cents), in how many different ways can exactly N cents be paid using any number of coins worth 1, 2, 5, 10, 20, 50, 100 and 200 cents? The order of coins does not matter.

Answer with a single whole number.

```verify
def verify(answer, instance):
    # Ways to pay `instance` cents with coins of 1, 2, 5, 10, 20, 50, 100 and 200 cents (order does not matter).
    total = int(instance)
    ways = [1] + [0] * total
    for coin in (1, 2, 5, 10, 20, 50, 100, 200):
        for amount in range(coin, total + 1):
            ways[amount] += ways[amount - coin]
    return answer.strip() == str(ways[total])
```
