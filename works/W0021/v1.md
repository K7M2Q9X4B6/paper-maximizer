# Attempt: 10 by 10 domino tilings by a signed determinant

## Problem and approach

For the 10x10 instance of W0014@1, I count complete coverings by horizontal or vertical dominoes, without overlaps or gaps. I read only the task header and statement, lines 1–18, before solving this instance. I did not consult its verifier or reference answer.

Color the cells as a checkerboard. A tiling pairs every black cell with one neighboring white cell. There are fifty cells of each color, so I build a fifty-by-fifty bipartite adjacency matrix B. Its rows index black cells and columns index white cells.

An ordinary adjacency determinant does not count tilings, because permutation signs can cancel. As a diagnostic I checked the smallest example: on a 2x2 board the unsigned matrix is all ones, its determinant is zero, and direct enumeration gives two tilings. That shortcut fails.

I instead give horizontal edges weight +1, and vertical edges in zero-based column c weight (-1)^c. The answer is the absolute value of the resulting signed determinant.

## Why the signing counts rather than cancels

Each nonzero determinant term corresponds to a perfect matching. Compare two matchings. Their differing edges form disjoint alternating cycles. On a cycle with 2k edges, changing the matching changes its permutation sign by (-1)^(k-1).

Every unit face of the grid has edge-weight product -1 under my signing. If the cycle encloses A unit faces, multiplying those face products cancels internal edges in pairs, leaving boundary-weight product (-1)^A.

Let I be the number of grid vertices strictly inside the cycle. Counting vertices, edges and unit faces gives A = I + k - 1. The cycle's interior vertices must match internally: its boundary vertices are already matched along the cycle, and edges cannot cross it. Thus I is even. Therefore the weight change is (-1)^(k-1), exactly compensating the permutation-sign change.

This holds for each alternating cycle, so all matching terms have the same sign. Their absolute sum, the absolute determinant, counts the tilings.

## Exact computation and independent check

I compute the determinant by fraction-free elimination, checking that every intermediate division is exact. Row swaps are tracked explicitly. No floating-point determinant or rounding is used.

For an independent computation, I recursively choose the first uncovered cell and try its legal right and downward domino placements. Memoizing the occupied-cell mask merges identical subproblems. Choosing the first empty cell means every tiling is generated exactly once: a domino covering it cannot extend to an earlier empty cell, because no such cell exists.

Both methods give the same integer for the full 10x10 board. I also compared them on all 24 positive rectangles with height and width at most five and area at most twenty. These comparisons help catch implementation mistakes; the signing argument explains the determinant method beyond those examples.

from functools import cache

def determinant(matrix):
    a = [row[:] for row in matrix]
    n = len(a)
    if not n:
        return 1
    previous, sign = 1, 1
    for k in range(n-1):
        pivot_row = next((i for i in range(k,n) if a[i][k]), None)
        if pivot_row is None:
            return 0
        if pivot_row != k:
            a[k], a[pivot_row] = a[pivot_row], a[k]
            sign = -sign
        pivot = a[k][k]
        for i in range(k+1,n):
            for j in range(k+1,n):
                numerator = a[i][j]*pivot - a[i][k]*a[k][j]
                assert numerator % previous == 0
                a[i][j] = numerator // previous
            a[i][k] = 0
        previous = pivot
    return sign*a[-1][-1]

def signed_count(h,w):
    if h*w % 2:
        return 0
    black = [(r,c) for r in range(h) for c in range(w) if (r+c)%2 == 0]
    white = {(r,c):i for i,(r,c) in enumerate((
        (r,c) for r in range(h) for c in range(w) if (r+c)%2))}
    matrix = [[0]*len(white) for _ in black]
    for i,(r,c) in enumerate(black):
        for dr,dc in ((0,1),(0,-1),(1,0),(-1,0)):
            if (r+dr,c+dc) in white:
                matrix[i][white[(r+dr,c+dc)]] = (-1)**c if dr else 1
    return abs(determinant(matrix))

def direct_count(h,w):
    full = (1 << (h*w))-1
    @cache
    def fill(mask):
        if mask == full:
            return 1
        free = full ^ mask
        p = (free & -free).bit_length()-1
        r,c = divmod(p,w)
        result = 0
        for q in ([p+1] if c+1 < w else []) + ([p+w] if r+1 < h else []):
            if not mask & (1 << q):
                result += fill(mask | (1 << p) | (1 << q))
        return result
    return fill(0)

for height in range(1, 6):
    for width in range(1, 6):
        if height * width <= 20:
            assert signed_count(height, width) == direct_count(height, width)
assert determinant([[1, 1], [1, 1]]) == 0
assert direct_count(2, 2) == 2
answer = signed_count(10, 10)
assert direct_count(10, 10) == answer
assert answer == 258584046368
