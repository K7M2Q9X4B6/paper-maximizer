# 서로 다른 소수의 합

인스턴스 `n`에 대해, n을 **서로 다른** 소수들의 합으로 나타내는 방법은 몇 가지인가? 더하는 순서는 따지지 않고, 소수 하나만으로 된 경우(n 자신이 소수일 때)도 한 가지로 센다.

예: 10 = 2 + 3 + 5 = 3 + 7 이므로 n = 10의 답은 2다.

답은 자연수 하나를 숫자로만 쓴다. 작은 인스턴스는 손으로 셀 수 있지만, 큰 인스턴스는 답이 수십 자리라서 정확한 계산 방법이 필요하다.

```verify
def verify(answer, instance):
    # n을 서로 다른 소수의 합으로 나타내는 방법의 수 (0/1 배낭 방식으로 센다)
    n = int(instance)
    sieve = bytearray([1]) * (n + 1)
    sieve[0] = sieve[1] = 0
    for i in range(2, int(n ** 0.5) + 1):
        if sieve[i]:
            sieve[i * i::i] = bytearray(len(sieve[i * i::i]))
    ways = [1] + [0] * n
    for p in range(2, n + 1):
        if sieve[p]:
            for a in range(n, p - 1, -1):
                ways[a] += ways[a - p]
    return answer.strip() == str(ways[n])
```
