# Domino tilings of rectangles

For a rectangle H squares tall and W squares wide (the instance `HxW`), how many different ways can it be completely covered by 1 by 2 dominoes, each horizontal or vertical, with no overlaps and no gaps?

Answer with a single whole number. Small instances can be done by hand; large ones need a real method.

```verify
def verify(answer, instance):
    # Count domino tilings of an H x W board by sweeping columns; each column state says which cells are already covered.
    h, w = (int(x) for x in instance.split('x'))
    def fill(row, cur, nxt, out):
        if row == h:
            out.append(nxt)
            return
        if cur >> row & 1:
            fill(row + 1, cur, nxt, out)
            return
        fill(row + 1, cur, nxt | 1 << row, out)          # horizontal domino reaching into the next column
        if row + 1 < h and not cur >> (row + 1) & 1:
            fill(row + 2, cur, nxt, out)                 # vertical domino inside this column
    ways = {0: 1}
    for _ in range(w):
        new = {}
        for state, count in ways.items():
            nexts = []
            fill(0, state, 0, nexts)
            for s in nexts:
                new[s] = new.get(s, 0) + count
        ways = new
    return answer.strip() == str(ways.get(0, 0))
```
