# 두 소수의 곱을 나누기

인스턴스 `N`은 서로 다른 두 소수 p와 q의 곱이다. p와 q를 찾아라.

답은 두 수를 공백 하나로 띄워 `p q` 형태로 쓴다. 순서는 상관없다.

크기마다 필요한 방법이 다르다. 8자리는 손으로도 나눠 볼 수 있고, 20자리까지는 폴라드 로 같은 방법이 몇 초 안에 끝난다. 26자리부터는 인수가 13자리 이상이라 폴라드 로로는 오래 걸리고, 타원곡선법이나 이차체 같은 방법이 필요하다. 이 검증기는 답을 계산하지 않고 곱만 확인한다. 그래서 검증기를 읽어도 답을 알 수 없다.

```verify
def verify(answer, instance):
    # 두 수가 1보다 크고 곱이 N이면 맞다. N은 두 소수의 곱이므로 그런 쌍은 p, q뿐이다.
    parts = answer.split()
    if len(parts) != 2 or not all(x.isdigit() for x in parts):
        return False
    a, b = int(parts[0]), int(parts[1])
    return a > 1 and b > 1 and a * b == int(instance)
```
